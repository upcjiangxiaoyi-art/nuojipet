# 糯叽 0.12.0 · 蹭蹭你

## 怎么玩

- 双击糯叽，或到设置的动作区点“蹭蹭你”。
- 她会偏头凑近、闭眼蹭两下，再慢慢坐好，约 4.2 秒。
- 单击仍是摸摸，长按仍是呼噜；“开心”仍可从设置预览。
- 开启“减少动态效果”时展示安静的偏头贴贴姿势，不循环摇晃。
- 独立预览也可以直接播放；4.2 秒后自动回到陪伴。

## 图层处理

保留原 PNG 皮肤。头部保持形状，只做平移和旋转；颈胸用逐行变化的变形衔接，爪子以下保持原位置。两只耳朵和闭眼层都使用头部的同一个变换。尾巴沿用独立尾根摆动，不随颈部拉伸。复用缓存图片直接绘制，无需额外截图合成或新增素材解码。

坐姿整体基准下移 24 个设计像素（默认显示尺寸下约 10 CSS px），为耳尖腾出余量，并改善坐姿相对其他姿态的落点。

## 检查与范围

- 421 个蹭蹭相位：爪子固定、脸部距离保持、颈胸无倒折、两次蹭动、动作首尾归位。
- 直接运行实际交互控制器并模拟时钟：结束待机、再次触发、打字打断、拖动打断、生成打断及旧定时器不会结束思考。
- 减少动态效果得到与时间无关的静态姿势。
- 独立 Canvas 渲染完整动作与原有姿态，检查闭眼跟随、耳尖边界和腿根；PNG 素材没有修改。
- 0.11.0 的 4,000 个行走相位回归通过。
- 当前环境没有真实 SillyTavern 或手机浏览器。本地 Canvas 的速度不能直接等同于手机性能，实际手势和流畅度仍需真机验收。

## 安装

把压缩包内 nuojipet-main 的内容覆盖进原来的糯叽扩展目录，不要另装重复实例，刷新酒馆。此包包含上一版行走修复。
