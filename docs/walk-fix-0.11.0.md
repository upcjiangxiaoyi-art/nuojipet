# 糯叽 0.11.0 行走修复

保留现有 2.5D 原画素材，修改分层变形与步态驱动，不包含新的三维模型。

## 修改原因

旧版绕肩髋旋转后整体下放腿部，根部也会偏离原位置。整体头身起伏又作用到脚掌，抵消了接地补偿。页面步幅和腿部实际水平运动不同，也会造成滑步。

新版固定肩髋，通过逐渐变化的图层位移让上腿随小腿弯曲；承重时爪子在局部坐标匀速后移，正好抵消页面前进。起伏和倾斜只作用于头身尾。抬爪与落地使用连续曲线。

## 检查结果与范围

- `node tools/test-walk.mjs`：4,000 个相位，检查根部固定、承重水平位移抵消页面移动、连续落地、变形无倒折、不同显示尺寸的步幅比例。
- 使用原生产 Canvas 渲染方法输出完整一圈与左右镜像，目视检查腿根、分层边缘与爪子。
- 独立渲染每条腿并扫描 alpha > 128 的爪底像素：前远 980、后远 983、前近 973、后近 973，抽样承重帧的各脚爪底高度均不变。远近脚沿用原图的透视地线。
- JavaScript 语法检查通过，原 PNG 素材未改动。
- 当前环境未运行真实 SillyTavern 和手机浏览器；页面层级、触摸、生成联动及手机性能需要实际安装后确认。本次没有重测这些既有功能。

## 安装和预览

把压缩包内 `nuojipet-main` 的文件覆盖到现有糯叽扩展目录内，保留你原来的安装目录名称，避免另装一份重复插件。刷新酒馆后点“糯叽走两步”。

`preview.html` 需经 HTTP 打开（例如在扩展目录运行 `python -m http.server 8000`，浏览器访问 `http://localhost:8000/preview.html`）。点击向左或向右走，勾选“暂停步态”后可拖动进度检查。开启“减少动态效果”时静止是预期行为。也可以直接查看 `walk-preview.gif`。
